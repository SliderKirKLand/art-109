# Common Ground

A collaborative drawing board built from the p5.js starter template. Everyone connected to the same server shares the same strokes in real time.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000` in two browser windows to test collaboration.

## Deploy on Render

Create a Render Web Service from this folder or from its GitHub repository. Render uses the included `render.yaml` file.

Build command: `npm install`

Start command: `npm start`

Use a Web Service, not a Static Site, because the app uses Node.js and WebSockets.

## Included tools

Brush, eraser, line, color selection, brush size, clear board, presence list, and PNG download.
